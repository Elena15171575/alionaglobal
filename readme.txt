СТРУКТУРА ФАЙЛОВ И ОПИСАНИЕ СТРАНИЦ ПРОЕКТА:

1. index.html — Главная страница («Об авторе»). Содержит форму заказа, 
   информацию о доставке, анонс лучших работ и юридические ссылки в подвале.

2. page133820556.html — Основная интерактивная Галерея. Включает в себя 
   адаптивный горизонтальный слайдер на 12 картин Алены Глобалл с полной 
   поддержкой мобильных устройств и исправленными стрелками навигации.

3. page133820476.html — Дополнительный Каталог-галерея. Настроена функция 
   плавного открытия оригиналов изображений во весь экран (Tilda Zoom) 
   по клику на фирменные красно-бордовые акцентированные кнопки (#c34747).

4. page133820656.html — Страница контактов. Центрированная карточка со 
   ссылками на Telegram, телефон и почту студии.

5. page74342589.html — Публичный Договор-оферта на оказание услуг по 
   разработке веб-дизайна и проектированию сайтов для студии САЙТЛАЙМ.

6. page74342591.html — Официальная Политика использования файлов Cookie.

7. 404.html — Брендированная страница ошибки 404 («Страница не найдена»). 
   Обеспечивает плавное удержание трафика и безопасный возврат на главную.

8. .htaccess — Конфигурационный файл для веб-серверов Apache на случай 
   переноса проекта с GitHub Pages на платный классический хостинг.
